# 🦷 Dantalaya — Crafting Beautiful Smiles

A modern, responsive dental clinic website built for **Dantalaya**, designed to provide patients with a simple and welcoming way to explore dental services, learn about the clinic, and request appointments.

🌐 **Live Website:** https://dantalaya-neon.vercel.app/

---

## ✨ About Dantalaya

**Dantalaya — Crafting Beautiful Smiles** is a dental clinic website created with a focus on clean design, accessibility, responsiveness, and a smooth patient experience.

The website introduces the clinic and its services while making important information such as clinic timings, contact details, location, and appointment options easily accessible.

## 💻 Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/amrita-kumari28/Dantalaya.git
```

### 2. Enter the project directory

```bash
cd Dantalaya
```

### 3. Install dependencies

Using pnpm:

```bash
pnpm install
```

### 4. Start the development server

```bash
pnpm dev
```

Then open:

```text
http://localhost:3000
```

in your browser.

---

## 🏗️ Production Build

To create a production build:

```bash
pnpm build
```

Run the production server with:

```bash
pnpm start
```

## 🌐 Deployment

The website is deployed using **Vercel** with continuous deployment connected to the GitHub repository.

Changes pushed to the `main` branch can automatically trigger a new production deployment.

## 🎯 Design Approach

Dantalaya was designed to feel like a **modern physical dental clinic rather than a generic medical template**.

The interface focuses on:

* Clean typography
* Comfortable spacing
* Simple navigation
* Clear calls to action
* Mobile-first responsiveness
* Easy access to appointment and contact options
* A calm and professional visual identity
